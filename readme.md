# Code Challenge

## Problem 1
### How to Run

1. Go to the problem1 folder:
   cd src/problem1

2. Run the file with Node.js:
   node index.js

## Problem 2
### How to Run

1. Go to the problem2 folder:
   cd src/problem2

2. Install the packages:
   npm install

3. Start the app:
   npm run dev

4. Open your browser and go to the link shown (usually http://localhost:5173)

### Features
- Swap between different tokens
- See token balances (mock data was created for each token)
- See USD values
- Click MAX to use full balance
- Click X to clear input
- Validations (throws error for insufficient balance, input < 0, required fields not filled, same tokens selected)
